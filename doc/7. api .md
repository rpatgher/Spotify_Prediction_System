# TrackWise API Documentation

**Version:** 1.0.0

---

# Authentication

All `/api/predictions` endpoints require authentication.

| Environment | Authentication |
|------------|---------------|
| Production | `Authorization: Bearer <Keycloak JWT>` |
| Development (`AUTH_ENABLED=false`) | `X-Debug-User: any-string` |

---

# Roles

| Role | Permissions |
|--------|------------|
| `usuario` | Analyze YouTube links, view history, delete own analyses |
| `productor` | All user permissions + upload audio files |

---

# Endpoints

## GET /health

Healthcheck endpoint. No authentication required.

### Response 200

```json
{
  "status": "ok"
}
```

---

## POST /api/predictions/youtube

Analyze a song from a YouTube URL.

The service downloads the first 60 seconds, extracts audio features using Essentia, runs the machine learning models, and stores the prediction.

**Roles:** `usuario`, `productor`

### Request Body

```json
{
  "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
}
```

| Field | Type | Required | Description |
|---------|------|----------|-------------|
| url | string | Yes | YouTube URL to analyze |

### Response 201

```json
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6"
}
```

The endpoint only returns the prediction ID.

Use:

```http
GET /api/predictions/{id}
```

to retrieve the complete analysis.

### Errors

| Status | Cause |
|----------|--------|
| 401 | Missing or invalid token |
| 422 | Empty URL or invalid request body |

## POST /api/predictions/mp3

Analyze an uploaded audio file.

**Roles:** `productor`

### Request

`multipart/form-data`

| Field | Type | Accepted Formats |
|---------|--------|----------------|
| file | binary | `.mp3` |

### Response 201

```json
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6"
}
```

### Errors

| Status | Cause |
|----------|--------|
| 400 | Unsupported file format |
| 401 | Missing or invalid token |
| 403 | User does not have producer role |
| 422 | File not provided |

## GET /api/predictions

Returns the authenticated user's prediction history.

Results are ordered from newest to oldest.

Only the user's own predictions are returned.

**Roles:** `usuario`, `productor`

### Query Parameters

| Parameter | Type | Default | Description |
|------------|------|----------|-------------|
| source | `youtube` \| `mp3` | — | Filter by source |
| limit | integer (1–200) | 50 | Maximum results |
| offset | integer ≥ 0 | 0 | Pagination offset |

### Response 200

```json
[
  {
    "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
    "source": "youtube",
    "inputName": "YouTube Analysis",
    "inputValue": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
    "createdAt": "2026-06-12T14:30:00Z",
    "rating": "B",
    "score": 78,
    "bestReleaseDate": "Friday, June 20, 2026"
  }
]
```

## GET /api/predictions/{prediction_id}

Returns the complete prediction detail, including:

- Audio features
- Summary
- Recommendations
- Predicted YouTube metrics

**Roles:** `usuario`, `productor`

### Path Parameters

| Parameter | Type | Description |
|------------|------|-------------|
| prediction_id | UUID | Prediction identifier |

### Response 200

```json
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "source": "youtube",
  "inputName": "YouTube Analysis",
  "inputValue": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
  "createdAt": "2026-06-12T14:30:00Z",
  "rating": "B",
  "score": 78,
  "bestReleaseDate": "Friday, June 20, 2026",
  "summary": "The song shows competitive potential within its market segment.",
  "features": [
```

## DELETE /api/predictions/{prediction_id}

Permanently removes a prediction.

**Roles:** `usuario`, `productor`

### Path Parameters

| Parameter | Type | Description |
|------------|------|-------------|
| prediction_id | UUID | Prediction identifier |

### Response 204

No content.

### Errors

| Status | Cause |
|----------|--------|
| 401 | Missing or invalid token |
| 404 | Prediction does not exist or belongs to another user |

# Schemas

## PredictionSummary

| Field | Type | Description |
|---------|------|-------------|
| id | UUID | Unique identifier |
| source | `"youtube"` \| `"mp3"` | Analysis source |
| inputName | string | Human-readable label |
| inputValue | string | Original URL or file name |
| createdAt | ISO-8601 datetime | Creation timestamp |
| rating | A–F | Rating grade |
| score | integer (0–100) | Layer 1 score |
| bestReleaseDate | string | Recommended release date |

---

## PredictionDetail

| Field | Type | Description |
|---------|------|-------------|
| summary | string | Narrative summary |
| features | array | Audio features |
| recommendations | array | Actionable recommendations |
| expectedViews | integer \| null | Predicted YouTube views |
| expectedLikes | integer \| null | Predicted likes |
| expectedComments | integer \| null | Predicted comments |

---

# Rating Scale

| Rating | Minimum Score | Meaning |
|----------|--------------|---------|
| A | 90 | High success potential |
| B | 80 | Good potential |
| C | 65 | Moderate potential |
| D | 50 | Moderate risk |
| E | 35 | Low potential |
| F | 0 | Requires significant improvement |

---

# Feature Item

| Field | Type | Example |
|---------|------|---------|
| name | string | `"Tempo"` |
| value | string | `"128 BPM"` |
| recommendation | string | `"The tempo is ideal for contemporary pop."` |

# Machine Learning Overview

| Layer | Model | Input | Output |
|---------|---------|---------|---------|
| Layer 1 | RandomForestRegressor | 50 Essentia audio features | Score (0–100) → Rating (A–F) |
| Layer 2 | 3 × RandomForestRegressor | Same 50 features + Layer 1 score | Expected Views, Likes, Comments |
