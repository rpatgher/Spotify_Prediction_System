# Spotify Prediction System

This repository has been organized into a standard machine-learning project structure.

## Project Structure

- `notebooks/` - exploratory and modeling notebooks
  - `Spotify_Success_Prediction.ipynb`
- `infrastructure/` - infrastructure artifacts and diagrams
  - `Infra.pkt`
- `data/raw/` - raw input datasets
- `data/processed/` - cleaned/feature-engineered datasets
- `src/` - reusable source code modules
- `models/` - trained model artifacts

## Notes

- Empty directories are preserved with `.gitkeep` files.
- Add new scripts and reusable logic in `src/` instead of notebooks when possible.
